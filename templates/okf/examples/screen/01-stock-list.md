# OBJ-110101：在庫一覧画面

> 例：一覧・検索画面の書き方。検索条件、ページング、並び替え、0 件時の扱いを本文に書き、API の入出力の型は契約（OpenAPI）に任せる（題材：在庫一覧画面）

## 概要

倉庫担当者・購買担当者が、倉庫ごとの商品在庫を条件で絞り込んで確認し、在庫の少ない商品を見つける。行を選ぶと在庫詳細画面へ進む。

## 状態表示

| 状態値 | 表示 |
|---|---|
| normal | 適正（表示色なし） |
| low | 少ない（黄色のラベル） |
| out | 欠品（赤のラベル） |

## 操作・イベント

| 契機 | 処理 |
|---|---|
| 初期表示 | 検索条件を初期値にして在庫検索API を呼ぶ。直前に検索していれば（詳細画面から戻ったとき）、その条件・ページ・並び順を復元する |
| 検索 | 入力チェック後、1 ページ目・現在の並び順で在庫検索API を呼ぶ |
| 列見出しのクリック | 並び替え。対象列：商品コード・在庫数・引当可能数・最終入出庫日。同じ列は昇順 → 降順を切り替え、1 ページ目から再検索。既定は在庫状態（欠品 → 少ない → 適正）、次に商品コード昇順 |
| ページ送り・表示件数の変更 | 条件・並び順を保ったまま在庫検索API を呼ぶ |
| CSV 出力 | 在庫CSV出力API を呼んでダウンロードする。10,000 件を超える場合は I-1103 を出して出力しない |
| 0 件 | 一覧の代わりに I-1101 を表示し、CSV 出力ボタンを無効にする |

## 入力チェック

| 項目 | チェック | メッセージ ID |
|---|---|---|
| 商品コード | 半角英数のみ | E-1101 |
| 商品名 | 50 文字以内 | E-1102 |
| 在庫状態 | 1 つ以上選ぶ | E-1103 |

## メッセージ

| ID | 種別 | 条件 | 文言 |
|---|---|---|---|
| I-1101 | 情報 | 検索結果が 0 件 | 条件に合う在庫はありません。条件を変えて検索してください。 |
| I-1103 | 情報 | CSV の対象が 10,000 件超 | 出力できるのは 10,000 件までです。条件を絞り込んでください。 |
| E-1101 | エラー | 商品コードに半角英数以外 | 商品コードは半角英数で入力してください。 |
| E-1102 | エラー | 商品名が 50 文字超 | 商品名は 50 文字以内で入力してください。 |
| E-1103 | エラー | 在庫状態が未選択 | 在庫状態を 1 つ以上選んでください。 |

通信エラー・タイムアウトはシステムの共通メッセージに従う。

## 権限

| ロール | データ範囲 |
|---|---|
| 倉庫担当者 | 所属倉庫の在庫のみ（倉庫プルダウンは所属倉庫だけ） |
| 購買担当者 | 全倉庫 |

範囲の絞り込みは API 側で行う（画面の制御は表示上のもの）。認可の方針は要件 SPC-110 を参照。
