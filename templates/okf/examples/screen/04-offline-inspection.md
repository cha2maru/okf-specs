# OBJ-010102：点検入力画面

> 例：スマホの圏外対応画面の書き方。通信状態と送信状態の表示、オフライン時にできる操作・できない操作を本文に書く。送信の仕組みは同期処理の側に書き、画面には重ねて書かない（題材：点検入力画面）

## 概要

点検者が現場（地下・山間部など圏外になりやすい場所）で、設備 1 台分の点検項目を入力し、写真を撮って端末に保存する。保存した結果は通信が戻ったときに同期処理が送る。

## レイアウト

`design/layout/inspection-entry.png`（縦向き固定。上部に通信状態バー、下部に保存ボタンを固定表示）

## 状態表示

通信状態バー

| 状態値 | 表示 |
|---|---|
| online | 表示しない（バーを畳む） |
| offline | 「圏外です。入力は端末に保存されます」（グレー） |
| syncing | 「送信中…（n 件）」（青） |

送信状態（1 件ごと）

| 状態値 | 表示 |
|---|---|
| draft | 入力中 |
| unsent | 未送信（オレンジ） |
| sending | 送信中 |
| sent | 送信済み（緑） |
| failed | 送信失敗（赤）。理由は一覧画面で確認 |

## 操作・イベント

| 契機 | 処理 |
|---|---|
| 初期表示 | ローカル設備マスタとローカル点検テーブルから表示する（通信しない）。同じ設備の draft があれば復元する |
| 入力の変更 | 3 秒ごとに draft としてローカル点検テーブルへ一時保存する（アプリが落ちても失わない） |
| 写真の撮影 | 縮小してローカル写真テーブルに保存する。端末の空き容量が 200MB 未満なら W-0103 |
| 保存 | 入力チェック後、syncStatus を unsent にして保存し、点検一覧画面へ戻る。オンラインなら同期処理に送信を依頼する（待たない） |
| 通信状態の変化 | 通信状態バーを切り替える。オンラインに戻ったときの送信は同期処理が行う |

### オフライン時の操作制限

| 操作 | オンライン | オフライン | 理由 |
|---|---|---|---|
| 点検項目の入力・保存 | ○ | ○ | 端末に保存するだけ |
| 写真の撮影・添付 | ○ | ○ | 同上 |
| 前回点検結果の詳細表示 | ○ | 端末にある分だけ | サーバーへ問い合わせない |
| 設備マスタの再取得 | ○ | ×（ボタンを無効） | 通信が必要 |
| sent の結果の修正 | × | × | 送信済みは修正不可（訂正は管理画面で） |
| unsent・failed の結果の修正 | ○ | ○ | まだサーバーにない |
| ログアウト | ○ | ×（未送信がある間は不可） | 未送信データを失わないため |

## 画面遷移

| 遷移元・契機 | 条件 | 遷移先 |
|---|---|---|
| 点検一覧画面で設備を選ぶ | | この画面 |
| 保存 | 成功 | 点検一覧画面（/structure/OBJ-010101.md） |
| 戻る | 入力がある | I-0102 で確認後、点検一覧画面（draft は残す） |
| アプリの再起動 | draft がある | 点検一覧画面に「入力途中があります」を表示（この画面へは直接戻らない） |

## 入力チェック

| 項目 | チェック | メッセージ ID |
|---|---|---|
| 点検項目 | すべて選択 | E-0101 |
| 項目コメント | 「否」の項目は必須、100 文字以内 | E-0102 |
| 写真 | 5 枚以内 | E-0103 |

## メッセージ

| ID | 種別 | 条件 | 文言 |
|---|---|---|---|
| E-0101 | エラー | 未選択の点検項目がある | 未入力の点検項目があります。 |
| E-0102 | エラー | 「否」にコメントがない | 「否」の項目には内容を入力してください。 |
| E-0103 | エラー | 写真が 5 枚超 | 写真は 5 枚までです。 |
| W-0103 | 警告 | 空き容量 200MB 未満 | 端末の空き容量が少なくなっています。電波のある場所で送信してください。 |
| I-0101 | 情報 | 保存した（オフライン） | 端末に保存しました。電波が戻ると自動で送信します。 |
| I-0102 | 確認 | 入力途中で戻る | 入力途中の内容は端末に残ります。戻りますか。 |

## 権限

点検者のみ。担当拠点の設備だけが端末に配信されるため、画面での絞り込みはない。
