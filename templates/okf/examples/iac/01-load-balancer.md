# OBJ-020101：公開ロードバランサー定義

<!-- システム SYS-02 クラウド基盤の共通方針（リージョン、命名・タグ規約、IaC ツール）に従う。ここには差分だけを書く。 -->

## 概要

予約システムの公開ドメイン `yoyaku.example.jp` で HTTPS を受け、パスに応じて予約画面の配信先と予約 API のコンテナへ振り分ける。TLS はここで終端し、WAF を前段に置く。

関連するリソース：

| リソース | 開発オブジェクト | 関係 |
|---|---|---|
| サーバー証明書 | OBJ-020102 公開証明書定義 | HTTPS リスナーに設定 |
| WAF | OBJ-020103 公開WAF定義 | このロードバランサーに関連付け |
| 公開用セキュリティグループ | OBJ-020104 公開SG定義 | 443／80 をインターネットから許可 |
| アクセスログ置き場 | OBJ-020301 ログ保管バケット定義（CMP-0203） | アクセスログの出力先 |
| 振り分け先（API） | OBJ-020401 予約APIサービス定義（CMP-0204） | ターゲットグループ `yoyaku-api-tg` |

## 設定値

| 項目 | 値 | 根拠（要件・非機能契約） |
|---|---|---|
| スキーム | インターネット向け | SPC-001（利用者がブラウザから予約できる） |
| 配置 | 公開サブネット 2 つ（AZ-a、AZ-c） | CTR-N-002 クラウド可用性 |
| リスナー 443 | HTTPS、証明書は OBJ-020102 | CTR-N-004 通信の暗号化 |
| リスナー 80 | 443 へ 301 リダイレクト（他の応答はしない） | CTR-N-004 |
| TLS ポリシー | TLS 1.2 以上、前方秘匿性のある暗号スイートのみ | CTR-N-004 |
| HSTS | `max-age=31536000; includeSubDomains`（応答ヘッダーに付与） | CTR-N-004 |
| アイドルタイムアウト | 60 秒 | CTR-N-001 応答性能（長時間の接続を想定しない） |
| リクエスト本文の上限 | 1 MB（WAF で判定） | CTR-F-001 予約API（本文は JSON のみ） |
| LB → コンテナ | HTTP（8080）、VPC 内に限る | SYS-02 共通方針（VPC 内は平文可） |
| 削除保護 | 有効 | ― |

### ルーティング

上から順に評価する。

| 優先 | 条件 | 振り分け先 | 備考 |
|---|---|---|---|
| 10 | パスが `/api/*` | `yoyaku-api-tg`（OBJ-020401） | CTR-F-001 予約API |
| 20 | パスが `/healthz` | 固定応答 404 | 外部から内部のヘルスチェックを叩かせない |
| 99 | 上記以外 | 画面配信の CDN オリジン（OBJ-020501） | 予約画面（SPA） |

### WAF

ルールの本体は OBJ-020103 に書く。ここで期待する振る舞いだけを示す。

| ルール | 動作 | 根拠 |
|---|---|---|
| マネージドルール（共通・既知の不正入力・SQL インジェクション） | ブロック | CTR-N-005 セキュリティ |
| 同一 IP から 5 分間に 2,000 リクエスト超 | 5 分間ブロック | CTR-N-005 |
| 国外 IP | カウントのみ（ブロックしない） | RUL-003 で国外からの予約を許可と裁定 |

## 冗長化・配置

マネージドのロードバランサーで、2 つの AZ に自動で分散する。片方の AZ が止まっても、もう片方で受け続ける。振り分け先のタスク数は OBJ-020401 で定める。

## セキュリティ

- 受ける通信は OBJ-020104 で 443／80 のみ。
- コンテナ側のセキュリティグループは、このロードバランサーの SG からの 8080 だけを許可する（OBJ-020402 に書く）。
- 応答ヘッダーからサーバー種別を消す。

## バックアップ・保持

- 設定は IaC が正本のため、バックアップはなし。
- アクセスログは OBJ-020301 へ 5 分ごとに出力し、保持は 400 日（同バケットのライフサイクルに従う）。

## 監視

| 監視項目 | 閾値 | 通知先 |
|---|---|---|
| 5xx 応答の割合（LB 自身） | 5 分間で 1% 超 | 運用チャネル（OBJ-020601 通知トピック） |
| ターゲットの 5xx 応答の割合 | 5 分間で 2% 超 | 運用チャネル |
| 正常なターゲット数 | 2 未満が 3 分継続 | 当番（電話） |
| 応答時間 p95 | 5 分間で 1.0 秒超 | 運用チャネル（CTR-N-001 の配分監視） |
| 証明書の有効期限 | 残り 30 日 | 運用チャネル |
| WAF のブロック数 | 5 分間で 500 件超 | セキュリティ担当 |

## 出力

| 値 | 用途 |
|---|---|
| ロードバランサーの DNS 名 | OBJ-020105 公開DNSレコード定義が参照（同じシステム内のため暗黙の契約） |
| ロードバランサーの SG ID | OBJ-020402 予約APIのSG定義が参照 |

他システムへ提供する値はない。
