# 要件

## 機能要件

- [SPC-001 モバイルアプリは点検項目の入力と写真の撮影・添付を受け付ける](/specifications/SPC-001.md)
- [SPC-002 モバイルアプリは圏外時も点検結果を端末内に保持する](/specifications/SPC-002.md)
- [SPC-003 モバイルアプリは通信回復時に未送信の点検結果と写真を自動送信する](/specifications/SPC-003.md)
- [SPC-004 クラウドは受信した点検結果と写真を保存する](/specifications/SPC-004.md)
- [SPC-005 ダッシュボードは拠点ごとの当月点検完了率を表示する](/specifications/SPC-005.md)
- [SPC-006 クラウドは異常ありの点検結果を受信したら拠点の管理者へメールで通知する](/specifications/SPC-006.md)

## 非機能要件

- [SPC-007 ダッシュボードは拠点進捗を 3 秒以内に表示する](/specifications/SPC-007.md)
- [SPC-008 クラウドは異常通知を点検結果の受信から 5 分以内に送信する](/specifications/SPC-008.md)
- [SPC-009 クラウドは平日 8〜20 時の稼働率 99.5% を維持する](/specifications/SPC-009.md)
- [SPC-010 システムは点検データを端末内・通信経路・クラウド上で暗号化する](/specifications/SPC-010.md)
