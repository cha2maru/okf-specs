# SPC-008：クラウドは異常通知を点検結果の受信から 5 分以内に送信する

## 受入基準

- **結果** 異常を含む点検結果の受信時刻から、メール送信 API の受付時刻までが 5 分以内
- 補足：メールが受信箱に届くまでの時間は外部サービス依存のため、基準は「送信 API の受付」までとする
