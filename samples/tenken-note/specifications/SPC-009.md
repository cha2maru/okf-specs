# SPC-009：クラウドは平日 8〜20 時の稼働率 99.5% を維持する

## 受入基準

- **結果** 月次の稼働監視レポートで、業務時間帯の稼働率が 99.5% 以上
- **結果** 1 つのアベイラビリティゾーン障害を模擬しても、点検 API とダッシュボードが利用できる
