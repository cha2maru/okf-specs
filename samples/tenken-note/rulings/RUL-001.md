# 裁定 RUL-001：点検業務の電子化について

## やりとり

| # | 話者 | 内容 |
|---|---|---|
| 1 | 利用者 | 現場の設備点検が紙で、事務所で毎回エクセルに転記している。スマホで点検して、事務所でまとめて見られるようにしたい。 |
| 2 | Claude | 点検する場所の通信環境はどうですか？ |
| 3 | 利用者 | 地下の機械室など、電波が届かない場所がけっこうある。 |
| 4 | Claude | 事務所で「まとめて見る」とき、特に知りたいことは何ですか？ |
| 5 | 利用者 | 拠点ごとに今月の点検がどこまで終わっているか。あと異常が見つかったらすぐ知りたい。 |
| 6 | Claude | サービスが止まって困る時間帯はありますか？ |
| 7 | 利用者 | 業務時間（平日 8〜20 時）に止まらなければいい。 |
| 8 | Claude | スマホを紛失した場合の心配はありますか？ |
| 9 | 利用者 | 点検データが外に漏れるのは困る。 |
| 10 | 利用者 | ついでに、既存の基幹システムと連携できるかも知りたい。 |
