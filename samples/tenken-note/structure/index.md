PRD-001 点検ノート
├─ SYS-01 モバイルアプリ（アプリ）
│   ├─ CMP-0101 点検入力（機能群）
│   │   ├─ OBJ-010101 点検一覧画面（画面）
│   │   └─ OBJ-010102 点検入力画面（画面）

│   │   └─ OBJ-020201 拠点進捗取得API（API：GET /sites/progress）
│   ├─ CMP-0203 異常通知（機能群）
│   │   └─ OBJ-020301 異常通知処理（イベント処理）

│   │   ├─ OBJ-020401 点検結果テーブル（テーブル）
│   │   └─ OBJ-020402 拠点テーブル（テーブル）

│   └─ CMP-0301 進捗ダッシュボード（機能群）
