# OBJ-020301：異常通知処理

## 概要

異常イベントを受け、拠点の管理者へメールで通知する。

## 処理

1. 異常イベントを受信する。
2. 拠点テーブルから siteId の管理者メールアドレスを取得する。
3. 件名「【点検ノート】異常検知：{設備名}」で、異常項目とダッシュボードの URL を本文に含めて送信 API を呼ぶ。

## エラー

| 条件 | 対応 |
|---|---|
| 管理者メール未登録 | ログに警告を出して終了 |
| 送信 API が 5xx・タイムアウト | 指数バックオフで最大 3 回再試行。失敗したらデッドレターへ |
