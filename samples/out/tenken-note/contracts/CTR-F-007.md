## 1. 契約内容

異常通知コンポーネントが「受け付けるメッセージ」として提供する。点検 API が発行側として利用する。

```json
{ "inspectionId": "string", "siteId": "string", "equipmentId": "string", "anomalyItems": ["code"] }
```

注：イベントの「提供者」を発行側にするか購読側にするかは、モデル上まだ決まっていない（サンプルで発見した論点）。
