## 4. 機能詳細

### 4.1 拠点進捗画面（OBJ-030101）

#### 4.1.1 概要

管理者が拠点ごとの当月の点検完了率を一覧で確認する。

#### 4.1.2 関連要求・要件

- REQ-003 管理者は拠点ごとの当月の点検進捗をダッシュボードで確認できる（要求・ユースケース）
- REQ-004 管理者は異常のある点検結果を発生後すぐに知ることができる（要求・ユースケース）
- SPC-005 ダッシュボードは拠点ごとの当月点検完了率を表示する（機能・利用）
- SPC-007 ダッシュボードは拠点進捗を 3 秒以内に表示する（非機能・配分）

#### 4.1.3 インターフェース

**画面項目**

| 項目 | 種類 | 表示内容 |
|---|---|---|
| 対象月 | 月選択 | 初期値は当月 |
| 拠点名 | 表示 | name |
| 対象数 | 表示 | total |
| 点検済数 | 表示 | done |
| 完了率 | 表示 | done / total を % で表示（小数点以下切り捨て） |

#### 4.1.4 処理内容

1. 表示時・対象月の変更時に GET /sites/progress を呼ぶ。
2. 完了率の昇順に並べ、50% 未満の行を強調表示する。

#### 4.1.5 使用データ

なし

#### 4.1.6 利用する契約（データ以外）

- CTR-F-004 管理API → 開発オブジェクト：OBJ-020201 GET /sites/progress

#### 4.1.7 エラー処理

| 条件 | 対応 |
|---|---|
| API エラー | 「進捗を取得できませんでした」を表示し再読込ボタンを出す |

#### 4.1.8 非機能要件（配分）

- CTR-N-001 ダッシュボード応答性能：描画 1.0 秒以内
