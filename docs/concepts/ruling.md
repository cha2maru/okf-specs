# 裁定

## 定義

利用者の発言と、それに対する質問・回答の一連のやりとりを、**その発言が何であるかを確定するまで**一つの単位として記録したもの。

```
発言（利用者）─┐
質問（Claude） ├─ 一連のやりとり ──→ 裁定：「これは何であるか」が確定
回答（利用者）─┘
```

- 発言には、プロダクトに対するものと、そうでないものが含まれる。
- 質問・回答を含めたやりとり全体を記録する。

## 行き先

裁定の結果、発言は次のいずれかに確定する。行き先は今後も増えうる。

| 行き先 | 内容 | 本設計での扱い |
|---|---|---|
| [要望](/concepts/wish.md) | プロダクトに対する要望 | **対象** |
| 調査 | プロダクトに直接すぐは反映されないもの | 今後の課題 |
| 開発ルール | 開発の進め方に関するもの | 今後の課題 |
| バグ報告 | 不具合の報告 | 今後の課題 |

## 契約の衝突の裁定

契約には主従がないため、契約内容と開発オブジェクトの差異、利用者どうしの食い違いなどの**衝突**も裁定の対象になる。
裁定の結果、契約・開発オブジェクトのどちらか（または両方）を改版する。記録形式は未決（未決事項 #29）。

## リレーション

- 裁定 → 要望：**1対多**。一つの裁定から複数の要望が生まれうる。
